    Coding sessions

    In File Explorer, right-click empty space in a folder and choose Open in terminal (godmode) to start Claude Code, Codex, Grok Build, Gemini or Cursor there with that CLI's own skip-permissions flag. On Windows 11 it is on the main right-click menu; the first launch asks once for administrator approval so Windows can trust it.

    Accounts

    Each tool's sign-ins on this computer are kept here. Click one to use it: the meters and the tool itself switch to that account at once. Add account keeps the current sign-in and runs the tool's own sign-in in a terminal; the new account joins the list when it is done. Saved copies are encrypted with this computer's keychain when it is available, and a tool's own login files are only written when you switch.
